Wer ist verantwortlich?

Verantwortlich für diese Website ist ihr Betreiber. Name und Kontakt stehen im Impressum.

Kurz gesagt

Diese Website setzt keine Cookies. Sie nutzt keine Analyse- oder Werbedienste und keine Inhalte fremder Server. Die Schrift (Archivo) liegt auf demselben Server wie die Seite.

Hosting bei GitHub Pages

Die Website liegt bei GitHub Pages, einem Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

Wenn du die Seite aufrufst, verarbeitet GitHub technisch nötige Daten, auch deine IP-Adresse. GitHub protokolliert Zugriffe, um den Dienst sicher zu betreiben (Server-Logs). Rechtsgrundlage ist das berechtigte Interesse an einem sicheren und stabilen Betrieb (Art. 6 Abs. 1 lit. f DSGVO).

Dabei können Daten in die USA übertragen werden. Einzelheiten stehen in der Datenschutzerklärung von GitHub.

Speicher in deinem Browser

Wenn du die helle oder dunkle Darstellung umschaltest, merkt sich die Seite deine Wahl in deinem Browser (Local Storage, Eintrag „netz-theme“). Dieser Eintrag verlässt dein Gerät nicht. Du kannst ihn jederzeit in den Einstellungen deines Browsers löschen.

Links zu anderen Seiten

Die Karte verlinkt auf die Website der TIB (tib.org). Wenn du einem solchen Link folgst, gilt dort die Datenschutzerklärung des jeweiligen Anbieters.

Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und Widerspruch. Außerdem kannst du dich bei einer Datenschutz-Aufsichtsbehörde beschweren.

Der Betreiber dieser Website speichert selbst keine personenbezogenen Daten. Zu den Server-Logs kann GitHub Auskunft geben.
