# Mallorca in Linien

Interaktiver Liniennetzplan für Bus, Bahn und Metro auf Mallorca. Ein Fanprojekt, keine offizielle Auskunft.

- Linien und Halte nach dem Netzplan der TIB (Transports de les Illes Balears), Stand März 2026.
- Fahrpläne und Tarife: [tib.org](https://www.tib.org/de/linies-i-horaris)
- Plakat A1: die Seite mit `#poster` am Ende der Adresse öffnen.

Eine statische Website ohne Build-Schritt: `index.html`, dazu CSS und JavaScript in `assets/`.
